# Backend API

This is an API built using [FastAPI](https://fastapi.tiangolo.com/), responsible for all endpoints for now.

## Run the application

Command to run :

- Install all dependencies: `uv sync --project backend`

- Run the application : `uv run --project backend python backend/main.py`
(Utilisez le lien du port 5000 depuis onyxia pour l'instant, en appuyant sur "ouvrir" votre vscode, pour accéder à la backend)
